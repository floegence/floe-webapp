# Temporary picomatch build dependency mitigation

The frozen workspace lock applies the local parser patch to every resolution of `picomatch@4.0.7`. It uses the single-repetition approach discussed in [upstream PR 267](https://github.com/micromatch/picomatch/pull/267), limited to one star with simple filename literals. For other single-branch wildcard repetitions covered by the guard, it uses the parser's existing literal fallback. Complex repeated extglobs are therefore not fully compatible; ordinary recursive file filters, extension lists and repeated character classes retain their behavior. This is a Floe build-tool mitigation, not an official picomatch release or a general-purpose fork.

`pnpm audit:dependencies` runs the same whole-workspace registry audit as CI and release. Only GHSA-fc5q-39xc-vjpf with the original package, version and no available fix is eligible. The check verifies the patch and installed parser hashes and rejects production paths. Other advisories and registry failures remain blocking. The exception expires at 2026-12-02 00:00 UTC. Once a fix is available, remove the patch and this exception, regenerate the lockfile and restore the ordinary audit command. Never transfer this exception to downstream consumers.
## Generated projects

The two Vite templates do not inherit the workspace exception. Their npm and pnpm overrides pin the independently published build-only `@ryotsu/picomatch@4.0.7-a`. Its tarball matches commit `3ab5a7627d480259e3d9ca67fbc14c125d374f0e`, a parser mitigation on the official master commit `9fab7bf61913ea334c4203ed321c426cfde44a42`. That baseline also includes upstream fixes for bracket negation, newlines and the scope of `**` adjacent to a literal. Release qualification checks the actual installed lock integrity and dev-only placement and runs the complete unmodified npm audit, typecheck and build for each scaffold. Remove the template overrides and integrity pin together when switching to a reviewed official fix. Floegence does not publish or maintain a matcher package.
